# Controle de Gastos

Painel financeiro do casal: lançamentos, receitas, contas fixas, metas, orçamento e um assistente que analisa cada lançamento.
Site estático (HTML, CSS e JavaScript puros, sem build), pronto para o GitHub Pages, com banco de dados no Firebase (Firestore + login Google), tempo real e modo offline.

Instalação, publicação e uso: veja [LEIA-ME.md](LEIA-ME.md).

Nenhum dado financeiro fica neste repositório. A configuração em `assets/js/firebase-config.js` é pública por natureza; o acesso aos dados é controlado por `firestore.rules`.
